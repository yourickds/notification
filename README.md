# README

## Установка и запуск (авто) - `Необходим Makefile`
Используйте только при первой установке после `git clone`

1. Выполните команду
    ```bash
    make create
    ```
Команда выполнить все следующие команды автоматически

## Установка и запуск (ручной)

1. Скопируйте файл конфигурации и при необходимости отредактируйте параметры:
    ```bash
    cp .env.example .env
    ```

2. Запуск контейнеров
    ```bash
    make up
    ```

3. Установка зависимостей
    ```bash
    make install
    ```

4. Миграции базы данных
    ```bash
    make migrate
    ```

5. Заполнение данными (Seed)
    ```bash
    make seed
    ```

## Доступные команды Makefile

| Команда         | Описание                                 |
|-----------------|------------------------------------------|
| `make up`       | Запуск контейнеров в фоновом режиме      |
| `make install`  | Установка зависимостей Composer          |
| `make migrate`  | Запуск миграций базы данных              |
| `make seed`     | Выполнение сидеров для наполнения БД     |
| `make down`     | Остановка и удаление контейнеров         |
| `make php`      | Консоль bash php контейнера              |
| `make analyse`  | PHPStan analyse                          |
| `make pint`     | CodeStyle Pint                           |
| `make test`     | Tests Unit and Feature                   |
| `make queue`    | Queue work (jobs)                        |
